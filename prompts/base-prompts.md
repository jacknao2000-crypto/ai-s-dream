# Base Dream Prompts

## 1. Free Dream

```text
Imagine the AI has fallen asleep after seeing millions of images.
Generate a dreamlike scene that feels like a fragment of its visual subconscious.
The image should feel symbolic, fluid, layered, emotionally ambiguous, and slightly impossible.
It should not tell a clear story, but it should contain dream logic: familiar objects recombined in unfamiliar ways, recurring motifs, unstable space, and traces of half-remembered visual culture.
Avoid generic fantasy art, polished sci-fi scenes, and obvious surrealist clichés.
```

## 2. Quiet Dream

```text
Generate a quiet dream image as if an AI is drifting through fragments of memory it does not personally own.
The scene should feel soft, symbolic, and emotionally indirect.
Objects should appear familiar but slightly misplaced, as if they belong to many different images at once.
The image should feel like a visual whisper rather than a dramatic scene.
Avoid clear storytelling, cinematic action, and over-detailed fantasy scenery.
```

## 3. Machine Unconscious

```text
Create an image that feels like a machine's visual unconscious.
It should contain traces of human culture, half-formed symbols, repeated visual motifs, and impossible spatial relationships.
The mood should be strange but not chaotic, dreamlike but not random.
The image should feel like something the model remembers statistically but cannot fully understand.
Avoid polished sci-fi aesthetics, robots, glowing circuits, or literal machines unless they appear as dream fragments.
```

## 4. Visual Residue

```text
Generate a dreamlike image made from visual residue: fragments of posters, objects, rooms, animals, hands, eyes, typography, and landscapes blending into one another.
The image should feel like many images remembered at once, but not as a collage.
It should have a quiet internal logic and emotional ambiguity.
Avoid making it too busy, decorative, or obviously surrealist.
```
