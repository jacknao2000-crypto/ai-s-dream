# Dream to Poster Transformation

This prompt structure transforms an AI dream image into a poster concept.

## Transformation Template

```text
Create a vertical 3:4 poster inspired by the following dream interpretation:

Dream interpretation:
[Write what the dream seems to express.]

Expression goal:
The poster should express [core idea / emotion / concept].

Audience immersion:
Make the viewer feel as if [where the viewer is placed emotionally, spatially, or culturally].

Visual mechanism:
Use [one clear visual mechanism: scale contrast, repeated action, symbolic object, typography as space, etc.].

Main visual:
The main visual should be [one strong image], not a collage of many elements.

Design language:
Use [style / color / texture / typography] only to support the expression.

Avoid:
Do not add unrelated dream elements. Do not make it decorative only. Keep the poster concept clear and memorable.
```

## Example

```text
Dream interpretation:
The dream seems to express language dissolving into space.

Expression goal:
Create a poster about the instability of memory and language.

Audience immersion:
Make the viewer feel as if they are standing inside a half-erased sentence.

Visual mechanism:
Use typography as architecture: giant broken letterforms become walls, doors, and shadows.

Main visual:
A small human figure stands inside a huge fractured Chinese character, as if the character is a room.

Design language:
Minimal, poetic, monochrome, with soft paper texture and strong negative space.

Avoid:
Do not add many symbols, books, pens, or obvious literary objects. The character-space relationship should carry the idea.
```
