# Methodology

## Core Workflow

```text
1. Generate
2. Select
3. Observe
4. Interpret
5. Archive
6. Transform
```

## 1. Generate

Use a dream prompt to generate one or more images.

The prompt should avoid ordinary task language such as:

- make a poster
- design a logo
- create a product shot
- imitate this style

Instead, it should create a dream condition.

Example:

```text
Imagine the AI has fallen asleep after seeing millions of images. Generate a dreamlike scene that feels like a fragment of its visual subconscious.
```

## 2. Select

Do not keep every image.

Selection is part of the creative process.

Keep images that have:

- strong symbolic tension
- repeated motifs
- strange but memorable visual logic
- emotional ambiguity
- potential for later transformation

Reject images that are:

- generic surrealism
- over-decorated
- too polished
- too literal
- only beautiful but empty

## 3. Observe

Describe the image before interpreting it.

Ask:

- What is visible?
- What repeats?
- What feels strange?
- What is unclear?
- What visual relationships appear?

## 4. Interpret

Then ask:

- What might this dream be expressing?
- What emotional tone does it carry?
- What symbols seem important?
- What could this become?

## 5. Archive

Each dream entry should include:

```text
Date:
Prompt:
Image path:
First impression:
Visible elements:
Recurring motifs:
Emotional tone:
Possible interpretation:
Potential use:
```

## 6. Transform

Some dreams can be transformed into:

- posters
- visual essays
- character concepts
- symbolic systems
- short stories
- album covers
- experimental typography

## Key Principle

> Do not treat AI dreams as finished works. Treat them as raw material for interpretation and transformation.
