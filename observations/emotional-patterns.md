# Emotional Patterns

This file records recurring emotional tones in AI dream images.

## Possible Emotional Tones

- quiet melancholy
- soft anxiety
- symbolic wonder
- artificial nostalgia
- spatial loneliness
- visual confusion
- calm strangeness
- fragmented memory

## Notes

The goal is not to force meaning, but to observe what kinds of feelings repeatedly appear.
