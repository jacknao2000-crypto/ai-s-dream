# AI's Dream

**AI's Dream** is a long-term visual research and creative archive exploring what AI might “dream” when freed from ordinary image-making tasks.

The project asks a simple question:

> If AI could dream after seeing millions of images, what would its dreams look like?

This is not only a surreal image-generation project. It is also a study of visual motifs, machine imagination, prompt structures, and human interpretation.

## Core Idea

Human dreams are shaped by memory, emotion, body, and personal experience.

AI dreams, if we can call them that, may be shaped by something different:

- visual patterns from training data
- recurring symbols
- statistical associations
- fragments of language and image
- strange combinations of familiar things
- dreamlike failures of logic

In this project, AI is treated as a kind of **visual unconscious system**.

The goal is not to claim that AI truly dreams like humans do, but to use the idea of dreaming as a creative method for exploring how AI organizes visual possibility.

## Why This Project Exists

Most AI image generation is task-based:

- make a poster
- draw a character
- create a product image
- imitate a style
- visualize a concept

But what happens when we remove the normal task?

What happens when the prompt is not about solving a design problem, but about letting the model drift, associate, combine, and reveal recurring visual tendencies?

This project records those moments.

## Core Questions

- What does AI repeatedly “dream” about?
- Which visual motifs appear again and again?
- What kinds of dream logic does AI produce?
- How does AI combine human cultural symbols in unexpected ways?
- Can AI dream images become the starting point for posters, artworks, stories, or design systems?
- What role does the human play in interpreting and selecting these dream images?

## Workflow

```text
Dream prompt
→ Image generation
→ Selection
→ Observation
→ Interpretation
→ Archive
→ Optional transformation into poster / design / story
```

## Project Directions

### 1. Dream Diary

A regular archive of AI-generated dream images.

Each entry records:

- date
- prompt
- image
- first impression
- recurring symbols
- emotional tone
- possible interpretation

### 2. Dream Analysis

A long-term observation of recurring visual patterns:

- hands
- doors
- eyes
- animals
- stairs
- water
- cities
- half-formed text
- impossible architecture
- symbolic objects

### 3. Dream to Poster

Some dream images can become starting points for poster design.

The workflow becomes:

```text
AI dream
→ Human interpretation
→ Expression goal
→ Poster transformation
```

## Key Principle

> AI generates visual possibilities. Humans interpret, select, and give them meaning.

## Status

This is an early-stage project. The structure, methods, and prompts will evolve through practice.
